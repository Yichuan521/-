一刻相册批量下载删除工具箱
专为**一刻相册网页版**设计的轻量级悬浮工具箱脚本，支持批量选择、自动下载、一键删除并循环执行，彻底解放双手，高效管理你的相册！

---

## ✨ 核心功能
- 🎯 **深度适配一刻相册**：预设一刻相册专属 DOM 选择器，无需额外修改即可直接使用
- 🎛️ **全参数可视化配置**：支持自定义单次选择数量（默认99张）、每一步操作的延迟时间，默认参数针对一刻相册优化
- 🖱️ **可拖动悬浮窗口**：仿桌面小工具设计，自由拖动避免遮挡相册内容
- 🔄 **自动循环处理**：无需重复点击，自动批量处理所有图片直到完成
- 🤖 **智能交互增强**：自动点击删除确认弹窗，完美适配一刻相册的弹窗样式
- 🛡️ **输入合法性校验**：非法参数自动重置为默认值，避免脚本异常
- ⏸️ **随时停止控制**：一键暂停操作，防止误执行或页面异常
- 💡 **轻量状态提示**：底部非弹窗式提示，不打断操作流程

## 🚀 一刻相册专属使用教程
### 1. 准备工作
1. 打开 **一刻相册网页版**：[https://photo.baidu.com](https://photo.baidu.com)
2. 登录你的账号，进入需要处理的相册列表页面（确保能看到图片缩略图）
3. 等待页面完全加载完成，确保所有图片项都已渲染

### 2. 启动工具箱
1. 按 `F12` 打开浏览器开发者工具（或右键页面 → 检查）
2. 切换到 `Console`（控制台）标签页
3. 复制本项目完整代码，粘贴到控制台并按回车键执行
4. 页面右上角会出现「图片批量处理工具箱」悬浮窗口

### 3. 配置参数（可选）
工具箱默认参数已针对一刻相册优化，你也可以根据需求修改：
| 配置项              | 默认值 | 说明                     |
|---------------------|--------|--------------------------|
| 单次选择数量        | 99     | 单次最多选择的图片数量（一刻相册单次上限为99张） |
| 选择后延迟(ms)      | 3000   | 选中图片后等待时间（适配一刻相册选中动画） |
| 下载后延迟(ms)      | 5000   | 触发下载后等待加载时间（确保一刻相册完成文件打包） |
| 取消选中延迟(ms)    | 3000   | 取消选中图片后等待时间 |
| 删除按钮延迟(ms)    | 3000   | 点击删除按钮后等待时间（适配一刻相册弹窗加载） |
| 确认删除延迟(ms)    | 3000   | 点击确认删除后等待时间 |
| 循环间隔延迟(ms)    | 2000   | 每次循环之间的间隔时间（避免频繁操作触发风控） |

### 4. 开始处理
1. 确认参数配置无误后，点击「开始循环处理」按钮
2. 脚本会自动执行：
   `选择99张图片 → 触发下载 → 等待5秒打包 → 取消选中 → 点击删除 → 自动确认删除 → 循环执行`
3. 所有图片处理完成后会自动停止并弹窗提示

### 5. 停止操作
- 如需中途停止，点击「停止操作」按钮即可
- 脚本异常或页面报错时也会自动终止并提示

## ⚠️ 重要注意事项
1. **合法使用**：本脚本仅用于个人合法的相册管理，请勿用于违反一刻相册服务条款的行为
2. **数据备份**：执行删除操作前，请确保已备份重要图片，避免数据丢失
3. **浏览器设置**：部分浏览器可能会阻止自动下载，需在浏览器设置中允许 `photo.baidu.com` 的下载权限
4. **临时脚本**：本脚本仅在当前页面会话有效，刷新页面后需重新执行代码
5. **风控提示**：频繁批量操作可能触发一刻相册的风控机制，建议适当调整延迟时间（如增加下载后延迟至6000ms）
